# 💎 CacheBot: AI-First Telegram Finance Mentor

Telegram-бот для осознанного управления личными финансами на базе **Zero-Based Budgeting (ZBB)**, поведенческой экономики и мультимодального ИИ **Google Gemini 1.5 Flash**.

---

## 🚀 Архитектура и стек

- **Backend:** Python 3.12 + FastAPI + aiogram 3
- **База данных:** PostgreSQL 16 (схемы: `users`, `envelopes`, `recurring_rules`, `goals`, `transactions`)
- **Кэширование и FSM:** Redis 7 (оперативные дневные лимиты, стейты Crisis Mode)
- **ИИ-движок:** Google Gemini 1.5 Flash (Vision для чеков и выписок, аудио для голосовых сообщений)
- **Планировщик:** APScheduler (утренний Drip-Feed и вечерняя «Сдача от лимита» в 21:00)
- **Визуализация:** Matplotlib (генерация диаграмм бюджета для команды `/stats`)

## 🛠 Запуск и настройка

### 1. Подготовка окружения
1. Скопируй шаблон конфигурации:
   ```bash
   cp .env.example .env
   ```
2. Укажи в `.env` свои ключи:
   - `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
   - `GEMINI_API_KEY` — ключ [Google AI Studio](https://aistudio.google.com/)

### 2. Запуск PostgreSQL и Redis через Docker
```bash
docker compose up -d
```
Скрипт `schema.sql` автоматически инициализирует все таблицы и типы в PostgreSQL.

### 3. Установка зависимостей Python
```bash
pip install -r requirements.txt
```

### 4. Запуск сервиса
```bash
python main.py
```
Сервер запустит:
- FastAPI API & Healthcheck на `http://localhost:8000/health`
- Telegram Long Polling бот
- Планировщик фоновых задач (APScheduler)

## 💡 Основные финансовые фичи

1. **Зарплатный пайплайн (`/salary 2500`):**
   - **Транспорт:** автоматически замораживает `[22 смены × тариф туда-обратно]`.
   - **Фиксированные платежи:** бронирует сумму обязательств (аренда, связь, кредиты).
   - **«Заплати себе» (20%):** отправляет в подушку безопасности.
   - **Drip-Feeding:** вычисляет `Safe_to_Spend_Лимит = Свободный_Остаток / Дней_До_Зарплаты`.
2. **«Умный Paywall» (`? 350` или `купить кроссовки 350`):**
   - Переводит стоимость покупки в чистые часы и рабочие смены твоей жизни:
     > *"Эти кроссовки стоят 24 часа твоей работы (3 полных рабочих дня). Они действительно нужны?"*
3. **Мультимодальный ввод трат:**
   - **Фото бумажных чеков:** автоматически берет только итоговую сумму и относит в `Супермаркеты / Продукты`.
   - **Скрины банковских приложений:** банкоматы (`ATM`) маркирует как перевод в наличные (не расход); проезд (`AUTOSTAN`, `Электричка`) списывает из транспортного фонда; обезличенные счета (`ЕРИП`) помечает для уточнения.
   - **Свободный текст:** `"14 маршрутка"`, `"обед 12 и кофе 4.5"`.
   - **Голосовые сообщения:** аудио распознается через Gemini AI.
4. **«Сдача от лимита» (в 21:00):**
   - Если потрачено меньше дневного Safe-to-Spend лимита, бот предлагает в 1 клик перевести разницу в копилку или в **Фонд выходных**.
5. **«Режим ЧП» (Crisis Mode):**
   - При перерасходе лимита бот предлагает выбор:
     а) Снизить лимит на оставшиеся дни недели.
     б) Покрыть перерасход из накопленного фонда выходных.
